# Vanguard Privacy — صفحة الهبوط والتطبيق

## الحالة الرسمية: الإصدار الأول (v1.0.0)

هذا المستودع هو **سطح ترخيص الإصدار الأول** من نظام **Vanguard Privacy** وتم حفظه رسمياً بوسم `v1.0.0`.
أي تطوير قادم (النسخة الثانية v2) سيبدأ من نسخة الرئيسية المحفوظة ولا يُمسّ هذا الإصدار.

## روابط النشر الحالية (مؤقتة)

- صفحة الهبوط: `https://vanguardprivacy.github.io/vanguard-www/`
- التطبيق: `https://vanguardprivacy.github.io/vanguard-www/app/`

> المنظمة الرسمية على GitHub: **Vanguardprivacy** (بدون اسم شخصي).
> عند الاستعداد للانطلاق تجارياً يُشتَرى **نطاق خاص** (مثل `vanguardprivacy.app`) ويُربط بهذه الصفحة
> عبر `CNAME` (ملف `CNAME` في جذر المستودع يحوي اسم النطاق) + سجل DNS `CNAME -> vanguardprivacy.github.io`.

## البنية

- `index.html` (الجذر) — صفحة الهبوط/البيع
- `app/` — تطبيق Vanguard Privacy الكامل (النسخة المنشورة)
- `icon.svg` — شعار الموقع (favicon/شارة التبويب)
